# Review lessons

Shared corpus of review feedback for this repo (operator comments + pre-reviewer findings). Builders read it before every plan; reviewers check every PR against it. Only the pr-team lead edits this file; others propose lessons to the lead. Commit it so the next run starts with it.

Format, one rule per line, imperative and checkable:

`- [<folder>|all|process] <rule> — <source: PR #, who>`

Use `[all]` when the rule is not about one folder (e.g. "a test for a fix must fail when the fix is reverted").
